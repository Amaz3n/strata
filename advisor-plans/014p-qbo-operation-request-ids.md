## Primary provider contract and outstanding verification

Parent rendered the public official [Intuit field definitions/request ID documentation](https://developer.intuit.com/app/developer/qbo/docs/learn/learn-basic-field-definitions#request-id) and [Intuit support article](https://help.developer.intuit.com/s/article/What-is-RequestId-and-its-usage) in a hidden read-only browser. The documented mechanism is query parameter requestid. IDs must be unique across all requests in a company. Nonbatch IDs permit up to 50 characters; batch IDs permit 36, with a separate bounded bId. Replaying the same ID and same content after a lost response returns the original response without repeating the operation. UUIDs are suitable. DocNumber is not this mechanism. No batch implementation is required here.
