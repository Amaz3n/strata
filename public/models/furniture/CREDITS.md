# Furniture models

Every model in this folder is from [Poly Haven](https://polyhaven.com) and is
licensed [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/): no
attribution is required, but we keep the source of each one here.

Textures were downscaled to 512 px for the web; geometry is unchanged. The
catalogue that names and sizes them is `lib/drawings/furniture-catalog.ts`.
